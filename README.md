# Contact Congress on AI

A static site that finds your two senators and House representative from your address. It then drafts an email, a call script or an in-person meeting plan aimed at that member's ideology and AI record. You choose which asks to include (RSI limits, independent evaluators/oversight, an international pause, protecting state AI laws from preemption, whistleblower protections) and which arguments to use.

## Layout

```
docs/            the deployable site (no build step)
  index.html     page + styles
  app.js         UI: address lookup, member cards, checkboxes, copy button
  generate.js    pure message generator (email / call / meeting, short / long); works in Node too
  data.json      angles, ideology defaults, 535 members, state hooks (generated, don't hand-edit)
  contacts.json  office phone + contact-form link per sitting member (generated by build_contacts.py)
  messages.json  hand-edited copy: which reasons start checked, local sentence per state, role sentences
scripts/
  export_data.py         research spreadsheet (.xlsx) -> docs/data.json
  build_contacts.py      congress-legislators dataset -> docs/contacts.json
  research_snapshot.xlsx copy of the research Sheet this data came from
tests/
  smoke.js, kind.js      Playwright smoke tests against a local server
```

## Run locally

```
cd docs && python3 -m http.server 8000   # then open http://localhost:8000
```

Opening index.html as a `file://` page won't work, because the page has to `fetch("data.json")`.

## Updating the data

1. Edit the research Sheet (tabs: Angles, Ideology defaults, Senate, House (120th), Governors, State hooks).
2. Download it as .xlsx.
3. Run `python3 scripts/export_data.py path/to/file.xlsx`. This rewrites `docs/data.json`.

The exporter reads columns by header name, so renaming a header will break it.

## Message copy (docs/messages.json)

- `startChecked`: each message starts with `count` reasons checked: up to `maxRecord` that tie to the member's own record (★), then the member's group list in order. The RELC overlay takes the last slot. Every checked reason goes into the message, with its sentence for each checked ask; a sentence shared by several asks is used once. The preemption and whistleblower asks have no reasons of their own.
- `local`: one line per state. It starts checked; states without one get no local point. A line is either a string or `{text, preempt, otherwise, to}`: `preempt` is added only when the preemption ask is checked (`otherwise` when it isn't), and `to` gives a thank-you version, keyed by member name, used when the message goes to the member the line names.
- `responsibilities`: an optional sentence for members with leadership or committee roles, keyed by name. It shows a "Reference responsibilities" checkbox. Call scripts reword it about the member ("Senator X decides").

## Contacts (docs/contacts.json)

Run `python3 scripts/build_contacts.py` after the data changes and again after members are sworn in (Jan 3, 2027). It matches members by chamber, state and name, so new members don't inherit a predecessor's office. Members who aren't sworn in get the Capitol switchboard instead.

It also records, for in-person meetings, each senator's meeting-request page (found by scanning their site; 63 of 79 sitting senators in Nov 2026) and every member's district offices from `legislators-district-offices.json`. When the visitor entered an address, the page lists the nearest offices first; the coordinates stay in memory and aren't stored.

Members of Congress don't publish email addresses; email goes through each member's website contact form. Senate links are the dataset's own or hand-checked ones. House links use the standard `<site>/contact` path; House sites block automated checks, so these aren't verified by the script.

## Address lookup: caveats

- As you type, the address box suggests matching addresses from [Photon](https://photon.komoot.io) (OpenStreetMap data, no key, CORS-enabled). Picking one looks up the district from that point with the Census geocoder's `coordinates` endpoint, so it doesn't depend on the Census matching the exact address text.
- Typed addresses without a pick still go to the Census `onelineaddress` matcher, which is strict. If it finds no match, the page opens the closest suggestions instead.
- Both Census calls use JSONP (no API key needed). Some hosts, CSPs or privacy blockers block it. If a suggestion was picked, the page still shows the senators for its state and asks for the district; otherwise it falls back to the state + district picker plus a link to house.gov.
- Photon's public server is fair-use. Requests are debounced (250 ms, 4+ characters). For heavy traffic, self-host Photon or swap in a keyed autocomplete service.
- Six states redrew their maps for 2026: CA, TX, MO, NC, OH and UT. Census data may lag, so the page warns users in those states to check their district. A more robust option is a district lookup that knows the 120th-Congress lines, such as Geocodio's `cd` field (needs a key, and calling it from a backend keeps the key private).
- DC and the territories aren't covered.

## Data caveats (as of 23 Nov 2026)

- LA-5 and LA-6 go to runoffs on Dec 12. Those cards stay disabled until the result rows are filled in.
- MN-1 may go to a recount.
- Ideology tags are heuristics for picking arguments, not ratings. "Confidence" means how much AI record we found.

## Hosting

Any static host works: GitHub Pages, Netlify, Cloudflare Pages. Point it at `docs/` (GitHub Pages: Settings → Pages → Deploy from branch `main`, folder `/docs`).
